## 1. Symptom

On the pre-fix RTL (`credit_out` registered), `t_fifo` passes every check while the independent property `P06` fails at 95 ns:

```
PASS: basic write/read
PASS: full and overflow protection
[95000] %Error: fifo_sva.sv:73: Assertion failed in TOP.t_fifo.dut.u_fifo_sva.a_p06_credit_iff_dequeue: P06 credit mismatch
```

A unit test and a property disagree about the same signal on the same run. The property is right: INTERFACE.md s6 makes `credit_out` combinational in the dequeue cycle.

## 2. Reproduce

The 2x2 below separates the defect in the test from the defect in the RTL. Re-run on 2026-11-03, Verilator 5.020, seed 1. Both commits are in the PR refs (`git fetch origin pull/13/head`).

```
git show f5ab0b9:rtl/front/input_fifo.sv > input_fifo_prefix.sv
git show ca65a74:rtl/front/input_fifo.sv > input_fifo_fixed.sv
git show f5ab0b9:tb/tests/t_fifo.sv     > t_fifo_prefix.sv
git show ca65a74:tb/tests/t_fifo.sv     > t_fifo_fixed.sv
# for each pairing:
verilator --binary --timing -Wno-fatal --timescale 1ns/1ps --top-module t_fifo <rtl> <tb> -o sim --Mdir o && ./o/sim +seed=1
```

| test \ RTL | pre-fix `f5ab0b9` (registered) | fixed `ca65a74` (combinational) |
|---|---|---|
| old `t_fifo` (`f5ab0b9`) | **PASS**, 86 checks, 0 failures — the test certifies the defect | **FAIL** at 120 ns: `credit returned after dequeue` |
| fixed `t_fifo` (`ca65a74`) | **FAIL** at 91 ns: `credit asserted during accepted dequeue` | PASS, 55 checks |

The top-right cell is the defect in the test: on correct RTL the old check fails. Signals: `clk`, `rd_ready`, `rd_valid`, `credit_out`, 85-125 ns.

## 3. Root cause

Two checks sampled `credit_out` after the negedge that follows the dequeue edge, by which time the test had already dropped `rd_ready`:

- `"credit returned after dequeue"`: `t_fifo.sv` line 97 at `66eb0fe`, line 127 at `f5ab0b9`
- `"simultaneous read returns credit"`: line 217 at `66eb0fe`, line 247 at `f5ab0b9`

Each is preceded by `rd_ready = 0;`. With combinational `credit_out = rst_n && do_read`, the credit is low by then, so these checks can only pass if `credit_out` is a register. They encode the registered timing, which contradicts INTERFACE.md s6 (`credit_out = deq`, same cycle) and s5.3 (the single register lives in `input_port`).

The test and the RTL were written together by the same author and carried the same reading of s6. The spec was right; both artefacts were wrong.

## 4. Fix

`ca65a74` moved both checks into the dequeue cycle: `"credit asserted during accepted dequeue"` samples `#1` after `rd_ready` rises with `rd_valid` high, and `"simultaneous read returns credit"` samples `#1` after the edge with the read still asserted.

Rejected: deleting the checks and relying on `P06` alone. That leaves the unit test unable to say anything about credit timing, and removes the redundancy that exposed the defect in the first place.

## 5. Escape analysis

**1. Which existing check should have caught this?** None existed that could judge a test. A unit test is only checked by the RTL it runs against, and here that RTL shared the error.

**2. Was anything asserting the wrong behaviour as correct?** This record *is* that thing: it is the second defect that PM-001's escape analysis identified.

**3. What else in this class could still escape?** Any timing check in a block's own test, written by the block's author, for a signal whose timing the spec fixes. Credit return at the `input_port` / `output_unit` boundary (`A10`, `R11`-`R14`) is the next place, and those properties are cross-owned by design. The structural defence is the ownership rule: the property author is not the RTL author.

## 6. Collateral sweep

Pattern: a check that samples an output after the stimulus that produced it has been removed. Searched:

```
grep -n 'check(credit_out' tb/tests/t_fifo.sv          # at f5ab0b9: lines 127, 220, 247
```

Line 220 (`!credit_out` after a rejected read) holds under either timing and is not affected. Lines 127 and 247 are the two above; both fixed in `ca65a74`. The current `tb_fifo.sv` on `main` carries the corrected same-cycle checks.

## Note for the paper

PM-001 and PM-002 together are the cleanest evidence for the independence rule. A co-written test and RTL agreed with each other and disagreed with the spec, and a cross-written property was what broke the tie. Report them as one event with two records, both pre-merge, neither counted.
